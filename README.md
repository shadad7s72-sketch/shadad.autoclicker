شـدّاد - Auto Clicker (shadadclic)
==================================

Project ready for GitHub Actions build.

Package name: com.shadad.autoclicker
App name: shadadclic
Theme color: blue

Instructions:
1. Push this repository to GitHub under your account (repo: shdado-autoclicker).
2. Ensure the default branch is 'main'.
3. Go to Actions tab and run workflow 'Build Android APK' or push to main.
4. After the workflow finishes, download the artifact 'app-release' which contains the APK.
